About DicomExtractor Pro

Three CBCT extraction workflows in one LAN application.

coDiagnostiX

Upload a matching .cdxPatient database and .cache file. The extractor writes classic DICOM slices, a ZIP package, and a validation report. A per-job option can reverse the left/right pixel order.

Open coDiagnostiX

RealGUIDE

Upload a supported RealGUIDE raw-project ZIP. The extractor writes DICOM slices, a ZIP package, and a validation report. Its axial orientation is assumed and must be verified before clinical use.

Open RealGUIDE

Future Case

Upload a Future/Anatomage .inv, an .exe wrapper, or a ZIP containing one. Recovery produces DICOM, NIfTI, previews, and a validation report. ZIP packaging and Z-order reversal are optional.

Open Future Case

Starting a new extraction

Choose an extractor from the home page, enter a patient ID, and upload the required source file or files. After extraction, the job reads the patient name from the Patient Name tag (0010,0010) in its resulting DICOM series. If the tag is empty, no name is shown. The job page shows progress, validation status, and available downloads.

Completed jobs open in the DICOM viewer automatically. The Viewer link in the top bar lists completed scans. Each scan has axial, coronal, sagittal, and threshold-derived 3D views, with STL export, key patient and date fields, grayscale controls, zoom, and pan.

Access on the local network

Sign in before uploading cases or viewing jobs and results. The administrator can create new users from the New user link; each account needs a @3ddx.com email address. Use Forgot password? on the sign-in page to request a one-time recovery code. Until email delivery is configured, the administrator can find active codes under Recovery and provide them to the account owner. Sign out when finished on a shared workstation.

Run start_server.bat on the PC hosting the project. Open http://localhost:8000/ on that PC. Other devices can use http://<server IPv4 address>:8000/ with an address shown by the launcher, if they can reach the PC over the LAN or VPN.

Each copy stores its own uploaded cases, results, and job history. Use one server address for everyone if you need a single shared job history.

If other PCs cannot connect, an administrator must allow inbound TCP port 8000 on the host PC. The project includes enable_lan_firewall.ps1 for this setup.
